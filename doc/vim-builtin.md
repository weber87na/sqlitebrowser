# 內建 Vim 操作說明（Windows 免安裝版）

本版本直接在 SQL 編輯器實作 Vim 操作。x64、x86 功能相同，不需 Neovim，
不讀取 init.lua、init.vim 或 Vim 外掛。解壓 ZIP 後執行程式，在偏好設定的 SQL
頁面啟用 Vim editing mode。Dracula 及既有字體設定保持可用。

## 模式與常用操作

| 按鍵 | 操作 |
|---|---|
| i / I / a / A | 游標前／行首／游標後／行尾插入 |
| o / O | 下方／上方開新行 |
| Esc 或 Ctrl+[ | 回到普通模式 |
| R | 連續覆寫，Esc 結束 |
| h j k l | 左下上右 |
| w b e / W B E | 字詞／空白分隔字串的移動，標點可獨立停靠 |
| ge / gE | 上一字詞／空白分隔字串的結尾 |
| Ctrl+A / Ctrl+X | 增加／減少目前行的十進位整數 |
| 0 / ^ / $ | 行首／第一個非空白字元／行尾 |
| gg / G / 12G | 檔案開頭／結尾／第 12 行 |
| f / F 加字元 | 行內往後／往前找到字元 |
| t / T 加字元 | 停在指定字元之前／之後 |
| ; | 重複上次字元跳轉 |
| { / } | 上一段／下一段 |
| ( / ) | 上一句／下一句（以 . ! ? 後的空白判斷） |
| H / M / L | 畫面上方／中間／下方 |
| Ctrl+D / Ctrl+U | 下／上半頁；數字前綴指定行數 |
| Ctrl+F / Ctrl+B | 下／上一頁 |
| zz / zt / zb | 目前行置中／移到畫面頂端／底端 |
| d / c / y 加移動或文字物件 | 刪除／變更／複製 |
| dd / cc / yy | 整行刪除／變更／複製 |
| x / X / s / S | 刪除後方／前方字元／替換字元／替換整行 |
| D / C | 刪除／變更至行尾 |
| p / P | 後方／前方貼上 |
| J / gJ | 合併行（整理行首空白）／直接移除換行 |
| >> / << | 增加／減少縮排 |
| == | 對齊上一行縮排；這不是 SQL 格式化器 |
| guw / gUw / guu / gUU | 字詞或整行轉小寫／大寫 |
| ~ | 切換字元大小寫 |
| u / Ctrl+R | 復原／重做 |
| . | 重複最近一次編輯，包含插入文字和 surround |
| v / V / Ctrl+V | 字元／整行／矩形選取 |
| 矩形選取後 d / y / c / I / A | 刪除／複製／變更／前方插入／後方附加；Esc 後套用到各行 |
| Ctrl+O / Ctrl+I | 上一個／下一個已記錄跳轉位置 |
| 選取後 o / gv | 交換選取端點／重選上一次範圍 |
| 選取後 J、u、U、~、>、< | 合併、大小寫或縮排 |
| ma / `a / 'a | 設定標記 a／回到位置／回到該行首個非空白字元 |
| qa … q / @a / @@ | 錄製巨集 a／執行 a／重複上次巨集 |
| "ayy / "ap | 複製到暫存器 a／貼上 a；大寫名稱可附加 |
| "_dd | 刪除並保留剪貼簿內容 |
| / / ? / n / N | 正向／反向搜尋、下一個／上一個結果 |
| * / # | 搜尋游標下的字詞 |

多數移動與編輯支援數字，例如 `3w`、`2dd`、`d2f,`、`3J`。
`Ctrl+W` 在插入模式刪除前一字詞，不會關閉 SQL 分頁。

## 文字物件與 surround

`iw`、`aw`、`iW`、`aW`、`i(`/`a(`、`i[`/`a[`、`i{`/`a{`、
`i"`/`a"`、`i'`/`a'` 可與 d/c/y 或選取搭配。

| 範例 | 結果 |
|---|---|
| ciw | 變更游標所在字詞 |
| di( | 刪除括號內文字，保留括號 |
| ysiw" | 將字詞包在雙引號內 |
| yss) | 將目前行包在括號內 |
| cs"' | 將雙引號改為單引號 |
| ds( | 移除外層括號 |
| 選取後 S" | 用雙引號包住選取範圍 |

## 你的預設快捷鍵

預設 leader 是逗號 `,`。

| 模式 | 按鍵 | 操作 |
|---|---|---|
| 插入／普通／選取 | ,, | 回到普通模式 |
| 插入 | zh / zl | 移到行首／行尾繼續輸入 |
| 插入 | z; / z, | 行尾加入分號／逗號，繼續輸入 |
| 普通 | zh / zl | 第一個非空白字元／行尾 |
| 普通 | z; / z, | 行尾加入分號／逗號 |
| 普通／選取 | ,ss | 搜尋 |
| 普通／選取 | ,ci | 切換註解 |
| 普通 | ,xs / ,xm | 儲存 SQL／開啟指令列 |
| 選取 | ,aa | 複製到系統剪貼簿 |

## 簡單設定檔

無需設定檔即可使用上述快捷鍵。需要調整時，可建立 `vim.json`，再設定
Windows 使用者環境變數 `DB4S_VIM_CONFIG` 指向其完整路徑，重新啟動程式。
若沒有環境變數，會讀取 Qt AppConfigLocation 下的 vim.json。

```json
{
  "leader": ",",
  "timeoutMs": 700,
  "shiftWidth": 4,
  "mappings": {
    "i:jk": "<Esc>",
    "n:Q": "gUw"
  }
}
```

`mappings` 鍵名前綴為 `i:`（插入）、`n:`（普通）、`x:`（選取），
右側為按鍵序列，支援 `<Esc>` 與 `<CR>`。只應對應到本說明列出的指令。
設定檔不是 Lua 或 Vimscript；不會執行外部程式。

## 指令列

普通模式按 `:` 或 `,xm`。Enter 執行，Esc 取消。

| 指令 | 說明 |
|---|---|
| :12 | 跳到第 12 行 |
| :w | 儲存 SQL 檔案（不是提交資料庫變更） |
| :s/foo/bar/ | 目前行第一個符合項目替換為 bar |
| :%s/foo/bar/g | 全檔所有符合項目替換 |
| :g/pattern/d / :v/pattern/d | 刪除符合／不符合正規表示式的行 |
| :2,5s/foo/bar/gi | 第 2–5 行替換，忽略大小寫 |

搜尋與替換使用 Qt／PCRE 正規表示式，並非 Vim 正規表示式語法。
替換支援 `\1` 等群組及 `&`（整個符合文字）。不支援確認旗標 c。

## 支援範圍

本版本是一套內建編輯引擎，並非完整 Vim。尚未提供 Vimscript、Lua 外掛、
LSP、終端機、Vim 視窗分割與完整 Ex 指令集。標記與巨集存於目前編輯器，
不跨重新啟動保存；標記會隨文字插入／刪除調整位置。
矩形插入限單行文字；換行或離開插入位置的編輯不會複製到其他行。
跳躍清單涵蓋一般跳轉，尚未提供完整跨檔案歷史；:global 目前僅支援上述刪除形式。設定不存在的指令不會自動獲得該功能。
