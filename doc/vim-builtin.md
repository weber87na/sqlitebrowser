# 內建 Vim 操作說明（Windows 免安裝版）

本版本直接在 SQL 編輯器實作 Vim 操作。x64、x86 功能相同，不需 Neovim，
不讀取 init.lua、init.vim 或 Vim 外掛。解壓 ZIP 後執行程式，在偏好設定的 SQL
頁面啟用 Vim editing mode。Dracula 及既有字體設定保持可用。

## 模式與常用操作

| 按鍵 | 操作 |
|---|---|
| i / I / a / A | 游標前／行首／游標後／行尾插入 |
| o / O | 下方／上方開新行 |
| Esc 或 Ctrl+[ | 回到普通模式 |
| R | 連續覆寫，Esc 結束 |
| h j k l | 左下上右 |
| w b e / W B E | 字詞／空白分隔字串的移動，標點可獨立停靠 |
| ge / gE | 上一字詞／空白分隔字串的結尾；可搭配 d/c/y，例如 dge、y2gE |
| + / Enter / - | 下一行／下一行／上一行第一個非空白字元，支援次數 |
| _ / 3_ | 目前行／往下兩行第一個非空白字元；d3_ 刪除含目前行共三行 |
| Ctrl+A / Ctrl+X | 增加／減少目前行的十進位整數 |
| 0 / ^ / $ | 行首／第一個非空白字元／行尾 |
| gg / G / 12gg 或 12G | 檔案開頭／結尾／第 12 行；gg 停在第一個非空白字元 |
| g_ / 3g_ | 目前行／往下兩行的最後非空白字元 |
| f / F 加字元 | 行內往後／往前找到字元 |
| t / T 加字元 | 停在指定字元之前／之後 |
| ; | 重複上次字元跳轉 |
| { / } | 上一段／下一段 |
| ( / ) | 上一句／下一句（以 . ! ? 後的空白判斷） |
| H / M / L | 畫面上方／中間／下方 |
| Ctrl+D / Ctrl+U | 下／上半頁；數字前綴指定行數 |
| Ctrl+F / Ctrl+B | 下／上一頁 |
| zz / zt / zb | 目前行置中／移到畫面頂端／底端 |
| za / zo / zc | 切換／展開／收合游標所在折疊 |
| zO / zC | 遞迴展開／收合目前折疊 |
| zR / zM / zv | 展開全部／收合全部／展開足以看見目前行的折疊 |
| d / c / y 加移動或文字物件 | 刪除／變更／複製 |
| dd / cc / yy | 整行刪除／變更／複製 |
| x / X / s / S | 刪除後方／前方字元／替換字元／替換整行 |
| D / C | 刪除／變更至行尾 |
| p / P | 普通模式：後方／前方貼上 |
| 選取後 p / P | 以暫存器取代選取；p 保存被取代文字，P 保留所有暫存器 |
| J / gJ | 合併行（整理行首空白）／直接移除換行 |
| >> / << | 增加／減少縮排 |
| == | 對齊上一行縮排；這不是 SQL 格式化器 |
| guw / gUw / guu / gUU | 字詞或整行轉小寫／大寫 |
| ~ | 切換字元大小寫 |
| u / Ctrl+R | 復原／重做 |
| . | 重複最近一次編輯，包含插入文字和 surround |
| v / V / Ctrl+V | 字元／整行／矩形選取 |
| 矩形選取後 d / y / c / I / A | 刪除／複製／變更／前方插入／後方附加；Esc 後套用到各行 |
| Ctrl+O / Ctrl+I | 上一個／下一個已記錄跳轉位置 |
| g; / g, | 上一個／下一個按鍵編輯位置；支援次數，最多保留 100 個位置 |
| 選取後 o / gv | 交換選取端點／重選上一次範圍 |
| 選取後 J、u、U、~、>、< | 合併、大小寫或縮排 |
| ma / `a / 'a | 設定標記 a／回到位置／回到該行首個非空白字元 |
| qa … q / @a / @@ | 錄製巨集 a／執行 a／重複上次巨集 |
| "ayy / "ap | 複製到暫存器 a／貼上 a；大寫名稱可附加 |
| "_dd | 黑洞刪除，保留剪貼簿與暫存器歷史 |
| "0p / "1p / "2p | 貼上最近一般複製／最近整行或跨行刪除／再前一次刪除 |
| "-p | 貼上最近一般單行小刪除 |
| / / ? / n / N | 即時正向／反向搜尋、下一個／上一個結果；支援 3/、3n、2N 等次數 |
| * / # | 搜尋游標下的字詞 |

多數移動與編輯支援數字，例如 `3w`、`2dd`、`d2f,`、`3J`。
`gg`、`g_`、`ge/gE` 和 `f/F/t/T` 也支援 Visual 與運算子組合，例如 `gUgg`、`dg_`、`d;`。
Visual 單獨的 `;` 會等待映射逾時（預設 700 毫秒），以保留 `;h`、`;q` 及自訂前綴；
下一鍵不屬於映射時則立即執行重複搜尋。反向重複的逗號仍由既有 leader 使用。
`3iabc<Esc>` 會插入 abc 三次；插入期間若移動到其他位置或改寫既有文字，則不重複。
`Ctrl+W` 在插入模式刪除前一字詞，不會關閉 SQL 分頁。
`Ctrl+H` 刪除前一字元；`Ctrl+U` 優先刪除目前行本次插入的文字；沒有新輸入時刪至行首，在行首則合併上一行。
`d+`、`d-`、`d<Enter>` 會整行刪除目前行到目標行；`c`、`y` 也可搭配這些移動。
移動已到文件邊界而無法前進時，運算子不會誤刪目前行；`d_` 仍代表刪除目前行。

`R` 逐字覆寫後，Backspace、`Ctrl+H/U` 可還原被覆寫的文字。此還原目前限逐字鍵入，
未涵蓋 `Ctrl+W`、IME、貼上、暫存器與補全產生的修改。

## 插入模式補全與暫存器

| 按鍵 | 操作 |
|---|---|
| Ctrl+N / Ctrl+P | 以游標前字詞為前綴，循環補全目前文件的候選字詞 |
| Ctrl+T / Ctrl+D | 增加／減少目前行縮排，對齊 shiftWidth 的整數倍 |
| Ctrl+O | 暫時執行一個完整普通模式指令後，返回插入模式 |
| Ctrl+R 再按 a | 插入暫存器 a 的文字 |
| Ctrl+R 再按 0 / 1 / - | 插入最近一般複製／整行或跨行刪除／單行小刪除 |
| Ctrl+R 再按 + | 插入系統剪貼簿文字 |
| Ctrl+R 後按 Esc | 取消暫存器選擇，保持插入模式 |

補全區分大小寫，支援 Unicode；候選包含原本前綴，可循環回到未補全狀態。
來源限目前文件；移動、編輯、選取或離開模式會重設候選，不提供 SQL schema 或跨分頁補全。
補全後的 `.` 保留已接受的文字；巨集則依執行位置重新搜尋候選。

例如插入時按 `Ctrl+O`、`2dw`，完成兩個字詞的刪除後即可繼續輸入；
暫存器前綴、運算子、映射、巨集和 Visual 操作會等完整指令結束。
`Ctrl+O :` 會等 Ex 指令完成或取消；逐筆替換則等確認結束才恢復插入。
`R` 中使用會返回覆寫模式，指令明確選擇 `i/a/c/o/R` 時則採用該模式。
`Ctrl+O` 分開前後插入的復原單位，取消原插入次數；後續 `.` 重複返回後的插入內容。

插入縮排保留游標相對文字的位置；`0 Ctrl+D`、`^ Ctrl+D` 的特殊形式尚未提供。
折疊操作使用編輯器既有語法折疊，不新增手動 foldmarker 或 Vim foldexpr；目前限普通模式。

`Ctrl+R` 支援 `a–z`、`A–Z`、`0–9`、`-`、`"`、`+`、`*`、`_`。
內容直接插入並轉為編輯器換行格式，不執行暫存器中的控制字元，也不模擬 Vim autoindent。
Windows 的 `*` 與 `+` 都使用系統剪貼簿；支援主要選取剪貼簿的平台則分開處理。

一般 yank 更新 `0`；指定具名暫存器的 yank 保留 `0`。
整行／跨行刪除與變更會將歷史往 `1–9` 推移；一般單行小刪除使用 `-`。
具名小刪除保留 `-`；大寫暫存器名稱會附加內容。少數 Vim 特例（例如單行 `d%`
也寫入數字暫存器）尚未涵蓋。暫存器只保存在目前編輯器工作階段。

Visual 字元／整行／矩形選取後，可輸入 `"a2p` 等指定來源與次數；來源會先快照，避免
被取代文字覆蓋來源。整行來源、整行選取與字元來源會按行形狀調整換行；
矩形選取支援 `p/P`：單行字元來源填入每列，區塊來源逐列插入，整行來源插在頂端行首；
多行字元來源只插入頂端一次。`p` 將被取代文字保存為區塊暫存器，`P` 保留暫存器歷史。
區塊來源也可貼到字元或整行選取；次數使每列水平重複，來源較高時補出所需行數。
短行以空格對齊，複製時保留矩形寬度；Tab 跨越邊界時只將受影響的 Tab 拆成空格。
整次替換可用一次 `u` 復原，並支援 Ctrl+R 重做及 `.` 重複。
欄位採用 Scintilla 的字元／Tab 欄位，不模擬終端 Vim 的東亞字寬、組合字寬或 `virtualedit`。

## 文字物件與 surround

`iw`、`aw`、`iW`、`aW`、`i(`/`a(`、`i[`/`a[`、`i{`/`a{`、
`i"`/`a"`、`i'`/`a'`、`ip`/`ap`、`is`/`as`、`it`/`at` 可與 d/c/y 或選取搭配。

| 範例 | 結果 |
|---|---|
| ciw | 變更游標所在字詞 |
| di( | 刪除括號內文字，保留括號 |
| dip / dap | 刪除目前段落／段落及相鄰分隔空白行 |
| cis / das | 變更目前句子／刪除句子及相鄰分隔空白 |
| vip / vis | 選取段落／句子 |
| cit / dat | 變更標籤內文／刪除包含標籤的範圍 |
| vit / v2at | 選取標籤內文／包含外一層標籤的範圍 |
| ysiw" | 將字詞包在雙引號內 |
| yss) | 將目前行包在括號內 |
| cs"' | 將雙引號改為單引號 |
| ds( | 移除外層括號 |
| 選取後 S" | 用雙引號包住選取範圍 |

段落以空白行及預設段落巨集邊界劃分；段落物件使用整行語義。
句子以 `. ! ?` 後的分隔空白或段落邊界判斷，支援尾端引號／括號，
不把中文全形句號自動當成額外句界。`ip/is` 的次數會將分隔空白視為一段，
例如 `2is` 包含目前句子及後方分隔空白；`ap/as` 的次數則擴張到更多完整段落／句子。
未提供 Vim 自訂 paragraphs/sections/cpoptions；反向反覆擴選仍有相容性限制。

`it/at` 支援巢狀同名標籤、含引號的屬性、HTML void／自閉合標籤，並略過
註解、CDATA、DOCTYPE 及處理指令；`script/style/textarea/title` 的內容按原始文字處理。
次數向外選取更多成對標籤；Visual 重複 `it` 依序擴大至目前標籤及外層。
標籤比對不分大小寫，採保守的整份文件結構檢查；任何未配對或錯誤標記都會取消操作。
不修復 HTML 可省略的結束標籤，也不提供 DTD、entity 或 schema 驗證。

## 你的預設快捷鍵

預設 leader 是逗號 `,`。

| 模式 | 按鍵 | 操作 |
|---|---|---|
| 插入／普通／選取 | ,, | 回到普通模式 |
| 插入 | zh / zl | 移到行首／行尾繼續輸入 |
| 插入 | z; / z, | 行尾加入分號／逗號，繼續輸入 |
| 普通 | zh / zl | 第一個非空白字元／行尾 |
| 普通 | z; / z, | 行尾加入分號／逗號 |
| 普通／選取 | ,ss | 搜尋 |
| 普通／選取 | ,ci | 切換註解 |
| 普通 | ,xs / ,xm / ,xf | 儲存 SQL／開啟指令列／開啟 SQL 檔案 |
| 選取 | ;q / ;h | 加上／移除各行的 SQL 字串包裝（+ '文字'） |
| 選取 | ,aa | 複製到系統剪貼簿 |

## 簡單設定檔

無需設定檔即可使用上述快捷鍵。需要調整時，可建立 `vim.json`，再設定
Windows 使用者環境變數 `DB4S_VIM_CONFIG` 指向其完整路徑，重新啟動程式。
若沒有環境變數，會讀取 Qt AppConfigLocation 下的 vim.json。

```json
{
  "leader": ",",
  "timeoutMs": 700,
  "shiftWidth": 4,
  "mappings": {
    "i:jk": "<Esc>",
    "n:Q": "gUw"
  }
}
```

`mappings` 鍵名前綴為 `i:`（插入）、`n:`（普通）、`x:`（選取），
右側為按鍵序列，支援 `<Esc>` 與 `<CR>`。只應對應到本說明列出的指令。
設定檔不是 Lua 或 Vimscript；不會執行外部程式。

## 即時搜尋

`/`、`?` 及既有 `,ss` 會開啟編輯器底部的搜尋列；輸入時預覽下一個符合項目，
並高亮目前文件中的非空符合範圍。搜尋區分大小寫，使用 Qt／PCRE 正規表示式，
支援 Unicode 與跨行 `^/$`；不使用 Vim 專屬正規表示式語法。

| 按鍵／指令 | 操作 |
|---|---|
| Enter | 接受搜尋；留空時沿用上次搜尋式 |
| Esc / Ctrl+[ | 取消並還原游標、Visual 選取、捲動位置與原先收合的折疊 |
| 上／下方向鍵 | 切換最近 100 筆搜尋歷史；回到最新位置會還原本次輸入草稿 |
| n / N | 依上次搜尋方向／反方向重複，越過文件邊界會循環 |
| 3n / 2N / 3/ | 依次數選擇符合項目；預覽與接受使用相同起點 |
| :noh / :nohlsearch | 清除搜尋高亮；下一次搜尋或 n/N 重新顯示 |

找不到符合項目或正規表示式無效時，預覽停回原位置；無效正規表示式按 Enter 不會提交。
接受的新搜尋會加入跳躍清單；暫時預覽及取消不會建立跳轉。
搜尋也可擴展 Visual 選取；插入模式 `Ctrl+O /` 會等搜尋接受或取消才返回插入。
搜尋列的鍵盤輸入可錄入巨集，映射也可使用 `/foo<CR>`。

搜尋高亮與 SQL 錯誤等其他指示器分開，文字變更時會更新符合範圍；零長度符合可跳轉，
但沒有可填色的文字範圍。停用 Vim 會清除高亮。焦點離開會取消預覽；外部修改文件時
會關閉搜尋列並取消暫時返回插入的狀態，避免使用失效的位置。
目前未提供 `:set incsearch/hlsearch` 選項、搜尋位移、`d/…` 運算子搜尋或跨文件搜尋歷史。

## 指令列

普通模式按 `:` 或 `,xm`。Enter 執行，Esc 取消。

| 指令 | 說明 |
|---|---|
| :12 / :$ / :.+2 | 跳到第 12 行／最後一行／目前行往下兩行 |
| :2,5d / :2,5y | 刪除／複製第 2–5 行 |
| :sort / :sort! | 全文排序／反向排序 |
| :2,5sort u | 第 2–5 行排序並移除重複行 |
| :'a,'bsort | 排序標記 a 到標記 b 所在行 |
| 選取後 : | 自動填入 '<,'>，後接 sort、d、y 或 s 等指令 |
| :w | 儲存 SQL 檔案（不是提交資料庫變更） |
| :s/foo/bar/ | 目前行第一個符合項目替換為 bar |
| :%s/foo/bar/g | 全檔所有符合項目替換 |
| :g/pattern/d / :v/pattern/d | 刪除符合／不符合正規表示式的行 |
| :2,5s/foo/bar/gi | 第 2–5 行替換，忽略大小寫 |
| :%s/foo/bar/gc | 全文逐筆確認替換 |
| :s/foo/bar/gc 3 | 從目前行開始三行，逐筆確認所有符合項目 |

行範圍支援數字、`.`（目前行）、`$`（最後一行）、`'a`（標記）及 `+/-` 位移，
以 `,` 分隔；`;` 會讓後一個相對位址以前一個位址為基準。`%` 代表全文。
未設定標記、越界、反向範圍或不支援的參數會拒絕執行。
排序使用區分大小寫的字典順序，尚未提供數值排序；保留換行格式與文件末尾是否有換行。

搜尋與替換使用 Qt／PCRE 正規表示式，並非 Vim 正規表示式語法。
替換支援 `\1` 等群組及 `&`（整個符合文字）。`c` 啟動逐筆確認：

| 確認鍵 | 操作 |
|---|---|
| y / n | 替換目前項目／跳過 |
| a | 接受目前與剩餘全部項目 |
| q / Esc / Ctrl+[ | 停止，保留已接受的修改 |
| l | 替換目前項目後停止 |

確認期間會選取目前符合文字；不必先關閉對話框。已接受的修改可一次復原；
全部拒絕不產生新的復原項目。外部文字修改、停用 Vim 或變成唯讀會取消確認。
外部編輯或滑鼠操作取消確認時，也會取消 Ctrl+O 返回插入的狀態，避免下一鍵意外進入插入模式。
如果主程式在外部編輯前先開啟巢狀 undo 群組，外部修改可能與本次確認共用復原項目。

## 支援範圍

本版本是一套內建編輯引擎，並非完整 Vim。尚未提供 Vimscript、Lua 外掛、
LSP、終端機、Vim 視窗分割與完整 Ex 指令集。標記與巨集存於目前編輯器，
不跨重新啟動保存；標記會隨文字插入／刪除調整位置。
矩形插入限單行文字；換行或離開插入位置的編輯不會複製到其他行。
跳躍清單涵蓋一般跳轉，尚未提供完整跨檔案歷史；:global 目前僅支援上述刪除形式。設定不存在的指令不會自動獲得該功能。

## 後續功能與驗證

完整分批清單見 [Vim 功能盤點與實作計畫](vim-roadmap.md)。
目前仍未提供完整 Ex、跨文件歷史及 Vim 外掛系統。
`g;`／`g,` 本批涵蓋按鍵編輯，尚未納入 Ex 編輯位置。

可在安裝 Qt5 開發套件及 QScintilla 的環境執行引擎測試：

```sh
cmake -S src/tests/vim-standalone -B vim-tests
cmake --build vim-tests
ctest --test-dir vim-tests --output-on-failure
```

測試通過與 Windows ZIP 封裝是兩個獨立階段；請以 PR 驗證紀錄和 Actions 附件為準。
同 repository 的 PR 可提供未簽章 x86／x64 可攜 ZIP，附件保留 7 天，附 SHA256；
它們不會自動發布成 Release。
