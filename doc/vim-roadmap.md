# 內建 Vim 功能盤點與實作計畫

本清單以 `vim-more-commands` 分支的內建編輯引擎為準。目標是完善 SQL 編輯器裡
常用的 Vim 操作，不依賴 Neovim、init.lua 或外掛。完整操作方式見 [操作說明](vim-builtin.md)。

## 判定方式

- **已驗證**：有 Qt/QScintilla 按鍵或指令回歸測試通過。
- **待驗證**：程式碼已完成，尚未取得測試結果。
- **待實作**：保留為明確的後續工作，不能視為可用。
- **部分支援**：僅提供表中說明的範圍，並非完整 Vim 相容。

## 原有能力

目前已有普通／插入／字元選取／整行選取／矩形選取，基本移動、計數、d/c/y、
貼上、復原／重做、`.`、巨集、標記、surround、文字大小寫、縮排、基本搜尋、
替換、跳躍清單與 JSON 自訂映射。既有支援不代表完整 Vim 所有邊界行為都相容。

## 後續評估（P3）

| 項目 | 規劃 |
|---|---|
| 持久化歷史 | 選擇性保存暫存器、巨集與標記，避免混用不同 SQL 文件位置 |
| 完整 register 種類 | 檔名、上次插入、上次 Ex、唯讀特殊暫存器；需整合文件生命週期 |
| 數字編輯 | Ctrl+A/X 的進位格式、前導零與 Visual 批次遞增 |
| 顯示行／欄位移動 | gj/gk、g0/g$、虛擬欄位與 tab 寬度一致性 |
| 可設定按鍵解析 | 擴充 <C-...>/<S-...> 與遞迴／非遞迴策略，避免無限映射 |

Vimscript、Lua 外掛、LSP、終端機、完整視窗／buffer 管理及外部 shell 過濾，
尚未納入本輪。若需要這些能力，應另行定義應用程式整合與安全邊界。

## 本輪驗證紀錄

- 已恢復本機 Qt 5.15.13／QScintilla 編譯與按鍵測試環境。
- 最終整合測試：**168 通過、0 失敗、0 跳過**。
- 同時修正先前 `dge` 預期值錯誤、失敗移動誤刪文字，以及 ge/gE 跳過空行。
- 修正 Ctrl+U 插入邊界、R 模式逐字覆寫退格還原，以及點號重複重新挑選補全候選。
- Windows workflow 新增以 vim-mode-windows 為目標的 PR 觸發，避免只驗證原分支推送。
- 本紀錄涵蓋 Linux 上的編輯引擎；Windows GUI、全程式及 ZIP 發布另行驗證。

## 交付原則

每批功能都要一起更新程式、回歸測試與中文說明。測試至少涵蓋正常按鍵、
計數、取消、UTF-8、Windows CRLF、唯讀及復原中與該功能相關的情境。
引擎測試通過不等於 Windows GUI 或免安裝 ZIP 已驗證；編譯、測試、打包狀態分開記錄。
