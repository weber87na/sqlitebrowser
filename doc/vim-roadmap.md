# 內建 Vim 功能盤點與實作計畫

本清單以 `vim-more-commands` 分支的內建編輯引擎為準。目標是完善 SQL 編輯器裡
常用的 Vim 操作，不依賴 Neovim、init.lua 或外掛。完整操作方式見 [操作說明](vim-builtin.md)。

## 判定方式

- **已驗證**：有 Qt/QScintilla 按鍵或指令回歸測試通過。
- **待驗證**：程式碼已完成，尚未取得測試結果。
- **待實作**：保留為明確的後續工作，不能視為可用。
- **部分支援**：僅提供表中說明的範圍，並非完整 Vim 相容。

## 原有能力

目前已有普通／插入／字元選取／整行選取／矩形選取，基本移動、計數、d/c/y、
貼上、復原／重做、`.`、巨集、標記、surround、文字大小寫、縮排、基本搜尋、
替換、跳躍清單與 JSON 自訂映射。既有支援不代表完整 Vim 所有邊界行為都相容。

尚未納入本輪。若需要這些能力，應另行定義應用程式整合與安全邊界。

- 新增實際 QObject 父子所有權的編輯器關閉測試，修正搜尋後關閉 SQL 分頁時的釋放順序存取。

## Ex 行編輯與替換歷史驗證

- `copy/co/t`、`move/m`：數字、標記、相對目的地址及開頭地址 0；保留暫存器與末尾換行。
- `join/join!`：預設、單地址、雙地址、次數與空白保留；越界或無效輸入不修改文字。
- `s`／`&`／`&&` 與普通模式 `&`：歷史、旗標重設／沿用、範圍與次數、空模式重用最近搜尋。
- 替換模板採單次解析，避免擷取的 `&` 或反斜線被二次展開；沿用既有逐筆確認。
- 本機完整回歸：**418 通過、0 失敗、0 跳過**；包含 LF／CRLF、中文、唯讀、無效指令、
  復原／重做、Visual 範圍、Ctrl+O、搜尋重用及重複確認。Windows 結果記錄於本批 PR。
- 未完成：`:global` 非刪除操作、`g&`／`:~`、完整替換旗標、搬移標記追蹤及 Ex 變更清單整合。

## 交付原則

每批功能都要一起更新程式、回歸測試與中文說明。測試至少涵蓋正常按鍵、
計數、取消、UTF-8、Windows CRLF、唯讀及復原中與該功能相關的情境。
引擎測試通過不等於 Windows GUI 或免安裝 ZIP 已驗證；編譯、測試、打包狀態分開記錄。
